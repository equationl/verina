# 统一转发记录

## 目标

为所有事件触发的 Webhook 提供可追踪的转发记录。最终失败记录始终可查；用户可选择保留全部成功、重试中和失败记录，并在 App 内查看完整请求与响应。

## 保留策略

1. 设置中提供“保留所有转发记录”开关，默认关闭。
2. 开启时，所有事件类型产生的 Webhook 记录均保留，直到用户手动删除。
3. 关闭时，成功记录不保留；重试成功后删除临时记录，最终失败记录保留最新 1000 条。
4. 同一次事件触发的同一个 Action 在重试期间更新同一条逻辑记录。
5. 数据库升级时迁移已有的最终失败记录。

## 记录内容

- 记录、规则和 Action 标识及规则名称。
- 事件类型、事件变量、触发时间和最后更新时间。
- 渲染后的 HTTP 方法、URL、请求 Headers 和 Body。
- HTTP 状态码、响应 Headers、完整响应 Body 和错误信息。
- 当前状态、已尝试次数和最大尝试次数。

## 列表与详情

1. 列表展示状态、事件类型、请求方法、URL、规则、错误摘要、尝试次数和时间。
2. 支持搜索 URL、规则、错误、变量和响应内容。
3. 支持按状态、事件类型和 HTTP 方法筛选。
4. 支持按触发时间、更新时间、状态、事件类型、HTTP 方法和规则名称排序，并支持升序/降序。
5. 支持详情查看和选择复制所有字段。
6. 搜索与筛选区域向下滚动时收起、向上滚动时显示；离开顶部后提供返回顶部按钮。

## 删除

1. 支持详情页单条删除。
2. 支持长按多选、全选当前筛选结果和批量删除。
3. 支持清空当前筛选结果和清空全部记录。
4. 删除操作需要二次确认；删除记录不取消正在进行的后台重试。

## 失败通知

Webhook 达到最大重试次数后发送失败通知。通知携带统一转发记录 ID，点击后无论 App 冷启动还是已打开，都直接导航到对应详情页。
