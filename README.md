# Verina

Verina 是一个 Android 事件驱动自动化工具：它监听手机上的事件，按你配置的规则执行动作。目前动作类型为 Webhook，可用于向自建服务、自动化平台或消息机器人发送请求。

## 开始使用

1. 安装并打开 App，在“设置”中开启“事件监听服务”。
2. 根据需要授予短信、电话状态、通话记录和通知权限。Android 13 及以上还需授予通知显示权限，才能显示后台服务通知。
3. 若要转发应用通知，在“设置”中点击“授予通知读取权限”，然后在系统页面中允许 Verina 读取通知。
4. 在首页点击 `+` 新建规则，选择触发事件，填写名称与 Webhook 动作后保存。

前台监听服务负责短信、来电与电量事件。通知转发由系统的通知读取服务提供；无需开启前台监听服务也可以接收通知，但建议始终开启它以保证其他事件可靠运行。

## 触发事件与插值变量

在 Webhook 的 URL、请求头和请求体中，可以使用 `{{变量名}}` 插入事件数据。所有事件都包含：

- `{{timestamp}}`：触发时的 Unix 毫秒时间戳。
- `{{formattedTime}}`：按设备地区格式化的时间，例如 `2026/07/22 12:34:56`。

### 短信接收

收到新短信时触发。

- `{{sender}}`：发件号码。
- `{{message}}`：短信内容（多段短信会拼接）。
- `{{receiver}}`：接收短信的 SIM 卡描述。

### 电话呼入

来电响铃时触发；相同号码在 3 秒内的重复响铃会被去重。

- `{{number}}`：来电号码。
- `{{state}}`：当前为 `ringing`。
- `{{receiver}}`：接听 SIM 卡的描述。

### 通知接收

收到任意应用的非持续通知时触发。短信、电话应用发出的通知也会包含在内。带有“正在运行”“下载中”等持续状态的通知不会转发，Verina 自己的后台通知也因此会自动排除。

- `{{packageName}}`：发出通知的应用包名。
- `{{appName}}`：发出通知的应用名称。
- `{{title}}`：通知标题；没有标题时为空。
- `{{text}}`：通知正文；没有正文时为空。

### 电量阈值

电池电量跨越设定的阈值时触发，可选择“从高到低”或“从低到高”。首次监听到的电量已经在阈值另一侧时也会触发一次。

- `{{level}}`：当前电量百分比。
- `{{threshold}}`：规则配置的阈值。

## 配置 Webhook 动作

每条规则可以配置一个或多个动作，按动作列表顺序执行。Webhook 支持 GET、POST、PUT、PATCH 和 DELETE，请求头默认是 `{}`，请求体可以留空。

示例：把收到的通知发送到一个 Webhook 服务。

```text
URL: https://example.com/hooks/notification
方法: POST
请求头: {"Content-Type":"application/json"}
请求体: {"app":"{{appName}}","title":"{{title}}","text":"{{text}}","time":"{{formattedTime}}"}
```

编辑规则时可以点击右上角“测试”。App 会使用示例数据替换插值变量并执行所有已填写的 Webhook，然后展示请求 URL、状态码、响应头、响应体或错误信息。

## Webhook 重试与转发记录

Webhook 首次发送失败后会进入后台重试队列，并按逐渐增加的间隔继续尝试。达到最大重试次数后仍未成功时，请求会被标记为最终失败，Verina 会发送失败通知；点击通知可以直接打开对应的转发记录详情。

在“设置 → Webhook”中可以开启“保留所有转发记录”：

- 开启时，保留短信、电话、通知和电量等所有事件产生的成功、重试中及最终失败记录，直到手动删除。
- 关闭时，不保留成功记录；重试期间只保留必要的临时数据，重试成功后自动删除，最终失败记录仍会保留。
- 关闭开关时的最终失败记录最多保留最新 1000 条，避免大量失败长期占用存储空间。

每条记录包含事件类型、规则、Action、事件变量、渲染后的请求 URL、请求头、请求体、HTTP 状态码、响应头、完整响应体、错误信息、尝试次数以及触发和更新时间。同一个事件产生的 Webhook 在重试期间更新同一条记录，不会为每次重试生成重复列表项。

转发记录页面支持：

- 搜索 URL、规则、错误、事件变量和响应内容。
- 按状态、事件类型和 HTTP 方法筛选。
- 按触发时间、更新时间、状态、事件类型、HTTP 方法或规则名称排序，并切换升序和降序。
- 长按进入多选，全选当前筛选结果并批量删除。
- 删除单条记录、清空当前筛选结果或一键清空全部记录。清理记录不会取消仍在进行的后台重试。
- 向下滚动时自动收起搜索与筛选区域，向上滚动时重新显示；离开顶部后可使用悬浮按钮快速返回顶部。

## 注意事项

- 通知内容由系统与发送应用决定；某些应用可能只提供标题或摘要，或因隐私设置隐藏正文。
- 手机重启、系统限制后台运行或关闭权限都会影响监听。建议开启“忽略电池优化”。
- Webhook 地址和内容可能包含敏感数据，请只配置可信的 HTTPS 服务。
- 转发记录可能包含通知正文、短信内容、电话号码、请求凭据和服务端响应。开启“保留所有转发记录”前请确认设备存储及隐私风险，并按需定期清理。
